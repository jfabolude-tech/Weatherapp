# Weatherapp
 A lightweight and responsive weather application built with HTML, CSS, and JavaScript. It allows users to search for any city and instantly view real-time weather conditions.

## ✨ Features
Search weather by city name

Displays temperature, humidity, and wind speed

Shows weather icons for clear, cloudy, rainy, etc.

Responsive design that works on desktop and mobile

Simple, clean UI with modern styling

## 🚀 How It Works
The app uses JavaScript to fetch live weather data from an external API (such as OpenWeatherMap) and displays it dynamically in the browser. No backend is required — everything runs client-side.

## 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

API: OpenWeatherMap (or any weather API of your choice)

## 📌 Usage
Clone the repository

Open index.html in your browser

Enter a city name in the search bar

Instantly view the latest weather details
